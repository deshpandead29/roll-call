# Challenges

Generated from `src/lib/missions.ts` (and mirrored in `prototype/index.html`). Keep this file and the code in sync. `{f}` is a friend picked by the app, `{b}` is the birthday person or the couple.

How they're written: each challenge is printed as the caption on the photo, so the prompt sets up a joke and the photo is the punchline, the way a Cards Against Humanity black card works. Specific beats generic ("The reason we're not allowed back", not "A fun moment"). Under 45 characters so it fits two caption lines. Funny about the group, never cruel about strangers, nothing dangerous or illegal.
